# Schedule

Target: 7–9 hours a week in term, 12–15 in sprints.

> **Fix the dates first.** Exam and break dates below are estimates from a typical US college calendar. Replace them with your real ones, then shift the rows around them.

## Weekly rhythm

| Day | Session | What it is for |
|---|---|---|
| Wednesday | 3–4 hour build block | New concept: read the brief, follow the tutorial, start the task |
| Sunday | 3–4 hour build block | Finish the task, test on the phone, commit, tick the checklist, write the log |
| Tuesday / Thursday evening | 30–45 minutes, optional | Reading and videos only, so Wednesday starts warm |
| Monday, Friday, Saturday | Off | Work days |

## Rules that keep the pace

- **Minimum week.** When life gets busy, one 90-minute session and one finished task still counts.
- **Overrun rule.** If a stage runs more than a week over, ship the core build, park the remaining quests in the backlog and move on.
- **Exam weeks.** No new work. Using the study tools you built counts.
- **Monthly check-in.** On the first Sunday of each month, compare [log.md](log.md) to this page and shift dates rather than skipping stages.
